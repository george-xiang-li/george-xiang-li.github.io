# George Xiang Li — GitHub Pages starter site

A lightweight static portfolio designed for GitHub Pages.

## Recommended GitHub setup

### Option A — simplest personal site URL
1. Create a GitHub account for George.
2. Create a public repository named exactly: `USERNAME.github.io`
3. Upload the contents of this folder to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. GitHub will publish the site at `https://USERNAME.github.io/`.

### Option B — keep any repository name
You can also use a repository such as `portfolio`. GitHub Pages can publish it at `https://USERNAME.github.io/portfolio/`.
